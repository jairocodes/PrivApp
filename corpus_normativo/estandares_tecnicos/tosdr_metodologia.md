# Metodología ToS;DR para evaluación de Términos de Servicio

## Fuente
ToS;DR (Terms of Service; Didn't Read) — tosdr.org  
Referencia: Guía de clasificación de puntos v3.0

## Categorías de evaluación

ToS;DR clasifica las prácticas en las siguientes categorías relevantes para este sistema:

### Categorías de riesgo ALTO
- Datos vendidos a terceros sin notificación clara
- Datos usados para publicidad dirigida sin consentimiento explícito
- No se puede eliminar la cuenta o los datos
- Datos entregados a gobiernos sin orden judicial
- Rastreo de usuario en otros servicios (cross-site tracking)

### Categorías de riesgo MEDIO
- Política de privacidad puede cambiar sin notificación
- Datos compartidos con afiliados sin definición clara
- Plazos de retención de datos no especificados
- Mecanismos de opt-out complicados o poco claros

### Categorías de riesgo BAJO / TRANSPARENCIA
- Datos no vendidos a terceros (declarado explícitamente)
- Usuario puede exportar sus datos
- Usuario puede eliminar su cuenta
- Notificación previa de cambios en la política
- Política redactada en lenguaje claro

## Aplicación en el sistema

Esta metodología complementa la taxonomía OPP-115 para asignar niveles de riesgo
a las cláusulas identificadas. Se usa como referencia de estándar técnico
(no como normativa legal vinculante).
